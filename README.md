# e等公務園+ 自動上課 下載

e等公務園+（E學中心）自動上課程式：自動登入、上課、考試、填問卷、列印證書。Windows 10／11 電腦用。

## 下載最新版

👉 **[點這裡下載最新版](https://github.com/fj80405/study-auto-release/releases/latest/download/study-auto.exe)**

## 第一次使用

1. 下載 `study-auto.exe`。
2. 在桌面或文件裡**新建一個資料夾**（例如「E學中心」），把 `study-auto.exe` 放進去。帳號、上課清單、證書都會存在這個資料夾裡，之後不要搬開。
3. 點兩下 `study-auto.exe` 打開。
4. 出現「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」（程式沒有買數位簽章，是正常的）。
5. 電腦要先裝好 Google Chrome。

## 之後更新

打開程式時會自動檢查，有新版會跳出「有新版本」，按「是」就會自己下載、換成新版、重新打開。帳號、上課清單、證書都會保留。
